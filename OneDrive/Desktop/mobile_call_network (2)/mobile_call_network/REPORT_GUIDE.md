## 2. INTRODUCTION (you can copy this and edit)
Mobile networks generate millions of call records every day. Each record shows who called whom, when, and for how long.
These records can be represented as a **graph**, where every mobile user is a **node** and every call between two users is an **edge**.
Analysing this graph gives useful information, such as which users are called most often and which users are almost disconnected from the network.

Such data is too large for one computer, so this project uses **Apache Spark**, an open-source cluster computing framework that divides data
into partitions and processes them in parallel on many machines. The project is written in **Python (PySpark)**.

**Objectives**
1. Load a dataset of mobile call records.
2. Construct a graph where nodes are users and edges are call connections.
3. Compute the most frequently called person.
4. Find isolated users who made or received very few calls.
5. Visualize the mobile call network.

**Technologies:** Apache Spark, PySpark (DataFrames), Python, NetworkX, Matplotlib.
